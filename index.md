# Markdown Viewer Online

Kho lưu trữ tài liệu Markdown miễn phí, công khai. Ai cũng có thể đóng góp thêm file.

## Xem tài liệu

- [MP Layer Analytics Design](mp_layer-analytics-design.md)

---

## Cách đóng góp tài liệu

Bạn có thể thêm file Markdown của mình theo 2 cách:

### Cách 1: Trực tiếp trên GitHub (không cần cài gì)

1. Truy cập [github.com/chuccv/MarkdownViewerOnline](https://github.com/chuccv/MarkdownViewerOnline)
2. Nhấn **Add file → Create new file** hoặc **Upload files**
3. Đặt tên file kết thúc bằng `.md` (ví dụ: `my-doc.md`)
4. Viết nội dung Markdown rồi nhấn **Commit changes**
5. File sẽ tự động xuất hiện tại `https://chuccv.github.io/MarkdownViewerOnline/my-doc`

### Cách 2: Fork và Pull Request

1. Fork repo về tài khoản của bạn
2. Thêm file `.md` vào repo đã fork
3. Tạo Pull Request về repo gốc
4. Sau khi được merge, file sẽ hiển thị trên trang

## Định dạng hỗ trợ

Trang này hỗ trợ **GitHub Flavored Markdown (GFM)**:

- Tiêu đề `#`, `##`, `###`
- Danh sách, bảng, code block
- Link, hình ảnh
- Checkbox `- [ ]`
